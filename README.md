# 🛒 SimpleEcommerce

A modern E-Commerce web application built using **Django**, **Bootstrap**, **HTML**, **CSS**, and **JavaScript**. The project provides a complete online shopping experience with product browsing, cart management, user authentication, wishlist, checkout, and order management.

---

## 📌 Features

- 👤 User Registration & Login
- 🔐 Secure Authentication
- 🛍️ Browse Products
- 🔍 Product Detail Page
- ❤️ Wishlist
- 🛒 Shopping Cart
- 💳 Checkout System
- 📦 Order Management
- ✅ Payment Success & Failure Pages
- 📱 Responsive Bootstrap UI
- 🛠️ Admin Dashboard
- 🖼️ Product Image Upload
- 📂 Category-wise Products

## 🚀 Installation

### 1. Clone Repository

```bash
git clone https://github.com/amankumarsharma-hub/SimpleEcommerce.git
```

### 2. Open Project

```bash
cd SimpleEcommerce
```

### 3. Create Virtual Environment

```bash
python -m venv venv
```

### 4. Activate Virtual Environment

**Windows**

```bash
venv\Scripts\activate
```

**Mac/Linux**

```bash
source venv/bin/activate
```

### 5. Install Dependencies

```bash
pip install -r requirements.txt
```

### 6. Apply Migrations

```bash
python manage.py migrate
```

### 7. Create Superuser (Optional)

```bash
python manage.py createsuperuser
```

### 8. Run Server

```bash
python manage.py runserver
```

Open:

```
http://127.0.0.1:8000/
```
